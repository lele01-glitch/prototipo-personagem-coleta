**Aluno:** Leticia Gabrielle Farina Santos
**Turma:** 2026.09.67
**Feito com:** Unity 6 e C# 
 
## Sobre o projeto 
- Prototipo de um jogo de coleta
 
## O que o projeto faz 
- ao encostar nos itens, eles somem e o placar aumenta

## O que o projeto contém 
- **Cenas:** MiniGame 
- **Scripts:** MoveJogador.cs – movimenta o jogador, soma os PickUp's coletados; PickUp - quando personagem encostar, irá ser destruído na hora. 
- **Objetos principais:** Player, Ground, PickUp's
- **Recursos usados:** Rigidbody, Character Controller, Collider com Is Trigger, TextMeshPro] 
 
## Controles 
- W,A,S,D – movimenta o personagem 
 
## O que eu aprendi 
Aprendi a como inicializar a modelagem de um personagem e como reprogramar partes que estavam erradas.
